RACE DAY ASSISTANT

Read README.md for exact deployment and iPhone installation steps, GPS/manual
instructions, offline verification, and pre-race / race-morning checklists.
Read AUDIT.md for the audit findings and completed tests.

Local preview: node serve.cjs, then http://localhost:8765
On iPhone, use the deployed HTTPS address and Add to Home Screen.

IMPORTANT: Original course and elevation data stop at 21.00 km. The final
100 m is unmapped. Follow race signs and use + KM to show FINAL 100 m.
All original pacing entries and course data are preserved.

Race flow: open app, wait for GPS match, press START RACE at the line.
Use - KM / + KM for manual strategy. GPS AUTO exits manual mode.
RECENTER only restores map following. RESET RACE requires confirmation.
